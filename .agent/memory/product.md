## Core concept
Users appear on a live map and can discover, match, and chat with people nearby. Onboarding collects profile data across 14 steps before granting map access.

## Onboarding flow (14 steps)
1. Nickname input
2. Date of birth
3. Gender identity (Erkek / Kadın / Non-binary)
4. Relationship intent (Arkadaşlık / Takılmak / Göreceğiz / Bir ilişki / Biraz eğlence / Evlilik / Açık ilişki)
5. Bio / about me (255 char limit, letters and numbers only)
6. Languages spoken (multi-select chips)
7. [Reserved]
8. Height & weight (sliders, cm/kg ↔ ft/lbs toggle)
9. Interests / passions (tag chips, max 10, two scrollable pages)
10. Profile photo upload (gallery or camera)
11. Location permission
12. Auth method selection (Apple / Google)
13. App store rating prompt
14. [Reserved / completion]

## Key screens (post-onboarding)
- **Map view:** live user pins with photo thumbnails, cluster badges, boost/events buttons
- **Swipe:** card-based discovery
- **Chat:** conversations list
- **Hub:** community / groups
- **Notifications**
- **Icebreaker:** gamified intro feature

## Navigation
Bottom tab bar — 5 items: Swipe, Chat, Hub, Notification, Icebreaker
Onboarding screens do NOT show bottom nav.

## Auth
Social login only: Apple and Google (no email/password).
